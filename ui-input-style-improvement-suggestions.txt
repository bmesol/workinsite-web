[34] Global: `input { box-shadow: none !important; }` override
     File: src/shared/styles/global.css (line 173)
     Issue: A global `input { box-shadow: none !important; }` rule removes all box shadows
            from every input element. The shadcn `Input` component uses `shadow-xs` as its
            base. While the focus ring uses `ring` (outline) rather than box-shadow, this
            `!important` can interfere with any third-party input components or custom shadow
            treatments added in future.
     Suggestion: Scope the rule to the app's own inputs if needed:
                 `[data-slot="input"] { box-shadow: none; }` (without !important). Or remove
                 it entirely if `shadow-xs` on inputs is acceptable.
     Reason: `!important` rules are hard to override and create specificity debt. The current
             global rule is broader than necessary.
     Priority: Low

            and `body { bg-background text-foreground }` rules.
     Suggestion: Remove the second `@layer base` block (lines 191–198) entirely. The first

     Reason: Avoids specificity conflicts; makes font size management explicit.
